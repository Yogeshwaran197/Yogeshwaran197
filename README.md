## About

Final-year **AI &amp; Data Science** engineering at SNS College of Engineering. I work the LLM stack end-to-end — **retrieval → generation → orchestration**.

- **Hybrid retrieval** — BM25 + dense, multi-query / HyDE expansion, parent-document retrieval, cross-encoder reranking (`FAISS`, `BAAI/bge-m3`)
- **Agentic systems** — LangGraph agents that synthesize their own tools and self-critique failures (`ChromaDB`, `Qdrant`, `Groq`)
- **Model specialization** — QLoRA fine-tuning of **Mistral-7B / Qwen2.5-7B** (`peft`, `trl`, `bitsandbytes`)

## 🔎 Currently Building

| Project | Technical line |
|---------|----------------|
| **Multi-stage RAG pipeline** | Hybrid BM25+dense retrieval, HyDE expansion, parent-document retrieval, cross-encoder reranking over LangChain |
| **AgentGraph** | Self-improving LangGraph agent that genes its own tools and self-critiques failures on every run |
| **QLoRA fine-tuning** | Mistral-7B / Qwen2.5-7B adapted with `peft` + `trl` + `bitsandbytes` on Hugging Face |
