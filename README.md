## About

Final-year **AI & Data Science** @ SNS College of Engineering. I build the LLM stack end-to-end: **retrieval → generation → orchestration**.

- **Hybrid retrieval** — BM25 + dense, multi-query / HyDE expansion, parent-document retrieval, cross-encoder reranking (`FAISS`, `BAAI/bge-m3`)
- **Agentic systems** — LangGraph agents that synthesize their own tools and self-critique failures (`ChromaDB`, `Qdrant`, `Groq`)
- **Model specialization** — QLoRA fine-tuning of **Mistral-7B / Qwen2.5-7B** (`peft`, `trl`, `bitsandbytes`)

## Currently Building

| Project | Stack |
|---------|-------|
| **Multi-stage RAG pipeline** | Hybrid BM25+dense retrieval, HyDE expansion, parent-document retrieval, cross-encoder reranking (LangChain, FAISS, BAAI/bge-m3) |
| **Self-improving LangGraph agent** | Agents that generate their own tools and self-critique failures on each run (ChromaDB, Qdrant, Groq) |
| **QLoRA fine-tuning** | Mistral-7B / Qwen2.5-7B adapted with `peft` + `trl` + `bitsandbytes` on Hugging Face |
