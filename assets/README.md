# Anime Gallery — add your GIFs here

The README references these 3 files. Download anime GIFs (from Tenor/Giphy/anywhere)
and save them in THIS `assets` folder with these exact filenames:

| Filename          | What to put                                              |
|-------------------|-----------------------------------------------------------|
| `one-piece.gif`   | a Luffy / One Piece animated scene                         |
| `bleach.gif`      | an Ichigo / Bankai / Bleach animated scene                |
| `aot.gif`         | an Attack on Titan / Survey Corps animated scene          |

How to get them:
1. Go to https://giphy.com or https://tenor.com and search (e.g. "luffy gear 5 gif").
2. Use the **"Copy Link" / media link that ends in `.gif`** (not the page URL).
3. Download the `.gif` file, rename it to the exact name above, and save it here.
4. In GitHub, upload these files to the `assets` folder of your profile repo.
